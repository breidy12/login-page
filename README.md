# 🔐 Página de Inicio de Sesión (Login Page)

Una página de **inicio de sesión simple y moderna**, creada con **HTML y CSS**.  
Incluye íconos de **Font Awesome** y una imagen de fondo a pantalla completa para un diseño atractivo y profesional.

## ✨ Características
- Diseño limpio y responsivo  
- Imagen de fondo con efecto de oscurecido  
- Botón con animación al pasar el cursor  
- Íconos de usuario y contraseña con Font Awesome  
- Código fácil de entender y personalizar  

---

## 🛠️ Tecnologías utilizadas
- **HTML5**
- **CSS3**
- **Font Awesome 7**
- **Visual Studio Code** (editor recomendado)
